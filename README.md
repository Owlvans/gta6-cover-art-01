GRAND LEONIDA — Leonida Cover Studio is a cast-mosaic GTA-style cover maker that runs fully offline in the browser. Eight built-in photographs — six characters (the Driver, the Boss, the Siren, the Fixer, the Lookout and the Runner), a getaway convertible and a neon motel — are laid out in thin gold frames over near-black beneath a sunset-striped chrome title, a glowing neon script subtitle, per-panel role tags, a five-star quote strip and a small-print billing block, all unified by a single sunset grade. Bring your own photos into the tray, drop them into any panel, pan and zoom each frame, rewrite the title, subtitle, tagline, quote and billing, switch between four colour grades, and export the finished cover as a PNG at 1080×1080, 1080×1350 or 1920×1080. Nothing is uploaded: every image stays on your own machine.

## Run it

```sh
node serve.ts  # then open http://localhost:8080
```
